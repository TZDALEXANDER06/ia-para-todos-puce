# IA para Todos - PUCE Sistemas

Sitio web del proyecto de vinculacion **IA para Todos: Educacion, Etica y Tecnologia**.

## Rol de Anthony

Anthony Orozco cumple el rol **E1 - Lider Web y Desarrollo Frontend**. La web centraliza videos, podcast, recursos, cronograma, equipo y evidencias del proyecto.

## Tecnologias

- Next.js con App Router
- TypeScript
- CSS global responsivo
- Google Analytics 4 mediante variable de entorno

## Desarrollo local

```bash
npm install
npm run dev
```

Luego abre `http://localhost:3000`.

## Configuracion

Copia `.env.example` a `.env.local` y ajusta:

```bash
NEXT_PUBLIC_SITE_URL=https://tu-dominio.netlify.app
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```
